El teu cançoner de guitarra

Com afegir cançons

Enganxa una cançó

A Biblioteca → ＋ Cançó, posa-hi un títol, enganxa el text a Acords i lletra i toca Desa. Mantén la línia d’acords i els seus espais.

C            G
Surt el sol, canto.

Importa un fitxer de text o ChordPro

A Ajustos → Importa JSON / text / ChordPro, tria un .txt, .cho o .chordpro. Revisa la cançó a l’editor i desa-la.

En ChordPro, posa cada acord entre claudàtors abans de la paraula on entra.

[C]Surt el sol, [G]canto.

Fes una còpia de la biblioteca

A Ajustos, toca Exporta biblioteca JSON per conservar les cançons, les versions i els repertoris. Per recuperar-los en aquest navegador o en un altre, toca Importa JSON / text / ChordPro i tria el .json.
